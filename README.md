# Java Assignment

This repository contains Java programming assignment solutions covering Object-Oriented Programming, Exception Handling, Multithreading, and the Java Collection Framework.

## Assignment Questions

### Q1. Employee Salary Management
**Concepts:** Inheritance, Method Overriding, Runtime Polymorphism

- Developer
- Manager
- Intern

### Q2. Online Payment System
**Concept:** Interface

- Credit Card Payment
- UPI Payment
- Net Banking Payment

### Q3. Bank Withdrawal
**Concept:** Exception Handling

- Custom Exception
- `throw`
- `try-catch`

### Q4. Railway Ticket Booking
**Concept:** Multithreading

- Multiple Threads
- `synchronized`
- Race Condition Prevention

### Q5. Student Record Management
**Concept:** ArrayList

- Add Students
- Search Student
- Remove Student
- CGPA Filtering

### Q6. Word Frequency Analyzer
**Concept:** HashMap

- Word Frequency Counting
- Key-Value Storage

### Q7. Hospital Emergency Queue
**Concept:** PriorityQueue

- Patient Priority
- Comparator
- Emergency Treatment Order

### Q8. Online Shopping Cart
**Concept:** HashMap

- Add Products
- Update Quantity
- Remove Products
- Calculate Total Cart Amount
